# Реестр рисков

Легенда: L/I — Likelihood/Impact (1–3); Score = L×I; ≥6 high, 3-4 medium, ≤2 low.
Mitigation — планируемые тестовые ID: `A-*` acceptance, `U-*` unit, `P-*` property
(hypothesis), `SEC-*` security, `E2E-*` end-to-end. Status: `open` → `covered`
после появления митигирующих тестов (заполняет qa-engineer); `accepted-residual` —
принятое остаточное ограничение (митигация не является автотестом); `resolved` —
закрыт решением владельца.
